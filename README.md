# Wacky Chef Showdown

Wacky Chef Showdown is a unique multiplayer cooking game where players compete in a chaotic kitchen, mastering the art of dish creation while sabotaging others!

## How to Play
- **WASD** to move
- **Mouse** to attack
- Collect items to cook delicious dishes and score points.

## Setup
1. Run `npm install`
2. Start the server with `node server.js`
3. Open `index.html` in your browser.

## Tech Stack
- Node.js
- Socket.io
- SQLite
- HTML5 Canvas

## Features
- Real-time multiplayer
- SQLite persistence
- Global leaderboard
- AI bots
- Client-side prediction
